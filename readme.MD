# OMR Evaluation Pipeline

This repository contains a pipeline for evaluating Optical Music Recognition (OMR) outputs against ground-truth MusicXML files using [Mupix](https://github.com/deepio/mupix), a Python-based tool for symbolic music comparison.

## Project Structure

```

./mupix/
├── pdf\_excerpts/             # Original score excerpts in PDF format
├── ground\_truth/             # Manually created ground-truth MusicXML files
├── omr\_outputs/              # Subfolders for each OMR tool's output
│   ├── newzik/
│   ├── photoscore/
│   ├── playscore2/
│   └── soundslice/
├── mupix\_results/            # JSON result files generated by Mupix
├── evaluation/               # Aggregated CSV summaries and result plots
├── run\_mupix\_comparisons.sh  # Shell script to batch-run Mupix comparisons
└── evaluate\_omr\_performance.py # Python script to summarize results and visualize metrics

````

## Setup

### Dependencies

- Python 3.8+
- [`mupix`](https://github.com/deepio/mupix)
- `pandas`
- `matplotlib`

To install the Python dependencies:

```bash
pip install pandas matplotlib
````

To install Mupix, follow the instructions at [github.com/deepio/mupix](https://github.com/deepio/mupix).

## Usage

1. Place original PDF excerpts into `pdf_excerpts/`.

2. Create the ground-truth MusicXML files and store them in `ground_truth/`.

3. Save the output MusicXMLs from each OMR tool into the respective `omr_outputs/<tool>/` subfolder.

4. Run the Mupix comparison batch:

   ```bash
   bash run_mupix_comparisons.sh
   ```

5. Run the evaluation and visualization script:

   ```bash
   python evaluate_omr_performance.py
   ```

This will:

* Compare each OMR output to its ground truth.
* Store result JSONs in `mupix_results/`.
* Generate:

  * `omr_category_summary.csv`: performance by category and excerpt
  * `omr_skipped_files.csv`: any skipped or invalid comparisons
  * `category_accuracy_summary.csv`: accuracy by category and tool
  * Accuracy plots (`accuracy_by_category_tool.png`, `total_accuracy_per_tool.png`)

All outputs are saved in the `evaluation/` directory.
